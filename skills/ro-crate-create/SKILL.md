# Creating an RO-Crate (spec 1.3)

Spec: https://www.researchobject.org/ro-crate/specification/1.3/

## Minimal structure
Place `ro-crate-metadata.json` in the crate root directory:

```json
{
  "@context": "https://w3id.org/ro/crate/1.3/context",
  "@graph": [
    {
      "@id": "ro-crate-metadata.json",
      "@type": "CreativeWork",
      "about": {"@id": "./"},
      "conformsTo": {"@id": "https://w3id.org/ro/crate/1.3"}
    },
    {
      "@id": "./",
      "@type": "Dataset",
      "name": "Title of the crate",
      "description": "What the crate contains",
      "datePublished": "2025-01-31",
      "license": {"@id": "https://creativecommons.org/licenses/by/4.0/"},
      "author": {"@id": "https://orcid.org/0000-0000-0000-0000"},
      "hasPart": [{"@id": "data/results.csv"}]
    },
    {
      "@id": "data/results.csv",
      "@type": "File",
      "name": "Results",
      "encodingFormat": "text/csv"
    },
    {
      "@id": "https://orcid.org/0000-0000-0000-0000",
      "@type": "Person",
      "name": "Jane Doe"
    },
    {
      "@id": "https://creativecommons.org/licenses/by/4.0/",
      "@type": "CreativeWork",
      "name": "CC BY 4.0"
    }
  ]
}
```

## Rules
- Root data entity: `@id` `./`, type `Dataset`, **MUST** have `name`, `description`, `datePublished` (ISO 8601), `license`.
- Every file/dir in the crate that matters is a data entity (`File`/`Dataset`) linked via `hasPart` (directly or transitively); directory `@id`s end with `/`.
- Every entity referenced (people, orgs, licenses, software) should be a contextual entity in `@graph`, with a stable identifier (ORCID, ROR, DOI) where possible.
- Use flat `@graph`; link with `{"@id": ...}`, never nest full entities.
- Only use terms from the context, or add full IRIs / extend `@context` for others.
- For software/workflows use `SoftwareSourceCode`/`ComputationalWorkflow` and the Workflow Crate / Workflow Run Crate profiles (`conformsTo` on the root).
- Add `ro-crate-preview.html` optionally; it is generated by tools.
- Never invent identifiers (ORCIDs, DOIs); ask the user.

## Workflow
1. Inspect the directory; list files.
2. Ask for/derive title, description, authors, license.
3. Write the metadata, then validate (see `ro-crate-tools` skill).
